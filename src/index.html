    Welcome to goclean! Create your first project in three steps:
    
      
      
        
    1. Open a new terminal (so the updated PATH is loaded)
      2. 
        
    2. Create a project
      goclean new myapp --database sqlite
      3. 
        
    3. Run it
      cd myapp && go run ./cmd/api
      4. 
      
    
      
    Uses SQLite so it runs with no setup; omit --database for PostgreSQL. Add features later with goclean make:module user. Docs: github.com/ebinskryfon/goclean
